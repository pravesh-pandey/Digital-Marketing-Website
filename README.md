# Digital Marketing Portfolio Website

A clean, modern single-page portfolio website designed to showcase your digital marketing work, client testimonials, and contact information.

## Features

- **Responsive Design**: Mobile-first approach that works perfectly on all devices
- **Easy to Update**: All content managed through a simple JSON file
- **Fast Loading**: Optimized HTML/CSS/JS with no heavy frameworks
- **Interactive Elements**: Smooth scrolling, animated testimonials carousel, and engaging micro-interactions
- **Spam Protection**: Contact form with honeypot spam protection
- **GitHub Pages Ready**: Configured for easy deployment
